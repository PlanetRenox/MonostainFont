Monostain

A free, programmatic monospace font from the Stain family, inspired by JetBrains Mono. Every glyph is drawn in code, and it's public domain.

fn main() -> Result<(), Error> {
    let mut sum = 0_u64; // every glyph is a centerline stroked by code
    for (i, x) in data.iter().enumerate() {
        if x % 2 == 0 && i != 7 { sum += *x; }
    }
    println!("total: {sum:>8} @ {:.2}%", 99.5);
}

Use it

@font-face {
  font-family: "Monostain";
  src: url("https://cdn.jsdelivr.net/gh/PlanetRenox/MonostainFont@1.0/dist/Monostain-Regular.woff2") format("woff2");
  font-weight: 400;
}
@font-face {
  font-family: "Monostain";
  src: url("https://cdn.jsdelivr.net/gh/PlanetRenox/MonostainFont@1.0/dist/Monostain-Bold.woff2") format("woff2");
  font-weight: 700;
}

code, pre {
  font-family: "Monostain", monospace;
}

Italics are at Monostain-Italic.woff2 and Monostain-BoldItalic.woff2. For editors and terminals, download the zip and install the .otf or .ttf files.
